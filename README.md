## Cómo usar

1. Descarga o clona el repositorio
2. Abre `web/index.html` en el navegador para ver la web
3. Abre `app/index.html` en el navegador para ver la demo de la app móvil
4. No requiere servidor ni dependencias — todo funciona abriendo el archivo directamente
